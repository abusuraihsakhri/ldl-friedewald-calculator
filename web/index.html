LDL cholesterol calculator

Estimate LDL-C using the Friedewald and Sampson-NIH equations. Values are calculated in your browser and are not sent to a server.

Lipid panel

Interpretation: Calculated LDL-C is an estimate, not a direct measurement. Results need clinical context and appropriate laboratory validation. Do not enter patient identifiers.

Results

Enter a lipid panel and select Calculate LDL-C.

Friedewald is not reportable at triglycerides ≥400 mg/dL. Sampson-NIH was developed for triglycerides below 800 mg/dL. A result below zero is withheld rather than clamped to zero.

CSV batch processing

Optional: choose a CSV file with total_cholesterol, hdl, and triglycerides columns in mg/dL. Each row is processed locally. CSV output includes both estimates, validity flags, and errors.

Methodology: Friedewald: TC − HDL-C − TG/5. Sampson-NIH (2020): TC/0.948 − HDL-C/0.971 − (TG/8.56 + TG × non-HDL-C/2140 − TG²/16100) − 9.44. The original Martin/Hopkins method requires a separate 180-cell factor table; a triglyceride-only shortcut is not that method.
